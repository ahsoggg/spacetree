# SpaceTree

[English](README.en.md) · [Русский](README.md)

Быстрый анализатор занятого места на диске для Windows (в духе WizTree / WinDirStat): дерево папок,
treemap, статистика по типам файлов, поиск и подсказки, что можно безопасно удалить. Плюс история
сканирований («что выросло за неделю?») и поиск дубликатов по содержимому.

![Обзор: дерево папок и treemap](docs/screenshots/02-overview.png)

*Все скриншоты сделаны на выдуманных данных (`SpaceTree.exe --demo`) — настоящих имён файлов на них нет.*

## Возможности

- **Два способа сканирования.** На NTFS с правами администратора SpaceTree читает таблицу MFT напрямую —
  целый диск за секунды (на HDD с 2 млн файлов: ~17 с против многих минут обхода папок). Без прав —
  параллельный обход папок через `GetFileInformationByHandleEx`.
- **Обзор:** дерево с сортировкой по имени, размеру, числу файлов и дате; treemap с анимированным
  приближением, раскраской по типу или по возрасту файлов, подсветкой выбранного расширения.
- **«Что выросло».** После каждого сканирования сохраняется небольшой снимок (размеры крупных папок).
  Вкладка «Что выросло» сравнивает текущее сканирование с прежним — по умолчанию с тем, что было около
  недели назад — и показывает виновника: `+12 ГБ в AppData\Local\Temp`. Если рост родительской папки
  целиком объясняется одной вложенной, показывается вложенная — список не забит всеми предками.
- **Настоящий поиск дубликатов.** Размер → хеш первых 64 КиБ → полный хеш BLAKE3. Дальше читаются только
  файлы, у которых ещё остался возможный двойник, так что большинство файлов не открывается вовсе.
  Самая новая копия в наборе остаётся (наведите курсор на строку, чтобы увидеть, какая именно). Запускается
  по кнопке, можно отменить.
- **«Можно удалить»:** временные файлы, кэши браузеров и программ, дампы, кэши npm/pip/cargo/Gradle,
  `node_modules`/`target`, старые установщики, корзина — с уровнями «безопасно / скорее безопасно /
  проверьте». Отметьте галочками и удалите в корзину или безвозвратно.
- **Удаление прямо из программы** (Del — в корзину, Shift+Del — безвозвратно) с подтверждением;
  дерево и статистика пересчитываются сразу, без повторного сканирования.
- **Жёсткие ссылки вместо удаления дубликатов:** кнопка «Схлопнуть в жёсткие ссылки» во вкладке очистки оставляет все
  имена на местах, но хранит данные одним экземпляром (NTFS, один том).
- **Сжатие LZX (Windows Compact)** из контекстного меню папки или файла: штатное прозрачное сжатие NTFS, обычно −30…50%
  на программах, играх и ассетах; программы запускаются как раньше. Не заходит в junction и symlink, есть «Снять сжатие».
- **Скрытые потоки NTFS (ADS):** вкладка и розовая подсветка на карте для файлов, у которых в `file.txt:имя` спрятаны
  мегабайты и гигабайты, невидимые Проводнику. Можно удалить отдельный поток (скан через MFT, нужны права администратора).
- **Живой режим:** значок «Live» внизу включает слежение через журнал USN — карта плавно перестраивается, когда
  что-то начинает писать гигабайты (скан диска через MFT, права администратора).
- **Осиротевшие данные:** папки в `AppData` без установленной программы и остатки удалённых игр Steam / Epic Games —
  отдельные группы «проверьте» во вкладке очистки; это догадка по именам, ничего не отмечается само.
- **Восстановление удалённых файлов (NTFS, нужны права администратора).** Кнопка «♻ Восстановление»:
  скан MFT находит удалённые файлы с именами и путями и оценивает шанс по битовой карте кластеров
  («целый / частично / перезаписан»); «Глубокий поиск» ищет JPG, PNG, PDF, ZIP/Office, MP4 и др. по сигнатурам
  в свободном месте. Предпросмотр, распаковка NTFS-сжатия, восстановление только на другой диск.
- Поиск по имени (Ctrl+F), крупнейшие файлы, типы файлов, экспорт в CSV, недавние пути,
  навигация стрелками, F5 — пересканировать.
- **Автообновление** из GitHub Releases с проверкой SHA-256 и подписи Ed25519 (можно отключить в настройках).
- **Журнал ошибок и отчёт о сбое** — для разбора проблем (см. ниже).

## Установка

Скачайте `SpaceTree-Setup.exe` со страницы [Releases](https://github.com/ahsoggg-creator/spacetree/releases/latest)
и запустите. Права администратора не нужны — программа ставится в `%LOCALAPPDATA%\Programs\SpaceTree`.

Установщик добавляет:

- ярлык в меню «Пуск» — SpaceTree находится поиском Windows по слову «spacetree»;
- пункт **«Сканировать в SpaceTree»** в контекстном меню папок, фона папки и дисков
  (в Windows 11 — в «Показать дополнительные параметры», Shift+F10);
- ярлык на рабочем столе (по желанию) и запись в «Приложения и возможности» для удаления.

Есть и переносная версия — просто `SpaceTree.exe`, её можно установить позже из настроек (⚙).

### Подпись кода

Исполняемые файлы релизов подписаны **самоподписанным** сертификатом `CN=ahsoggg`
([`certs/ahsoggg.cer`](certs/ahsoggg.cer), отпечаток SHA-256
`83A7AA2EA6B3787AD9573F4EB7D3A588C081235368F0079284DB5C1E6EFF0828`).

Самоподписанный сертификат не выдан удостоверяющим центром, поэтому честно о том, что он даёт и чего не даёт:

- Он позволяет проверить, что скачанный файл — именно то, что подписал автор, и что релизы подписаны одним
  ключом (сверьте отпечаток выше).
- Он **не** убирает предупреждение SmartScreen: пока сертификат не добавлен в доверенные на вашем
  компьютере, Windows пишет «неизвестный издатель». Если вы доверяете автору, импортируйте сертификат для
  своего пользователя: `powershell -ExecutionPolicy Bypass -File scripts\trust_cert.ps1` (сначала скрипт
  печатает отпечаток).

Закрытый ключ хранится только у автора; файлы `*.pfx` исключены из git.

## ИИ-помощник и MCP (необязательно)

По умолчанию выключено. Включается в настройках (⚙ → *ИИ-помощник*) и работает только с локальной
[Ollama](https://ollama.com): адрес обязан быть `localhost` / `127.x.x.x` / `[::1]`, прокси и редиректы отключены,
так что наружу запросы не уходят. Отдельным явным переключателем можно выбрать **Claude Code (облако)**: SpaceTree запускает ваш установленный `claude -p` (по подписке, без инструментов и доступа к диску), и тогда имена, размеры и даты уходят в Anthropic. Модели передаются имена папок и файлов, размеры и даты — не содержимое.

- ПКМ по папке → **Что это за папка? (ИИ)** — что это, можно ли удалять и что произойдёт.
- Кнопка **✨ Словами** рядом с поиском — «архивы и установщики больше 500 МБ старше полугода, кроме games».
  Модель лишь пишет JSON-фильтр, сопоставление делает код SpaceTree (`core::query`).
- Вкладка «Что выросло» → **Объяснить, что выросло**.

`spacetree-cli --mcp` — SpaceTree как MCP-сервер (stdio) для ИИ-агентов редактора (Lumen Code, Claude Code…):
инструменты `scan`, `list_folder`, `find`, `explain_folder`, `cleanup_candidates`, `what_grew`. Только чтение,
без сети; удалять сервер не умеет.

## Диагностика и приватность

SpaceTree ничего никуда не отправляет, кроме проверки обновлений на GitHub (ИИ-помощник, если вы его включили, говорит только с локальной Ollama). Для разбора проблем локально
хранятся:

- `%APPDATA%\SpaceTree\logs\spacetree.log` — сканирования, неудавшиеся удаления, проблемы с обновлением
  (ротация при 512 КБ);
- `%APPDATA%\SpaceTree\logs\crashes\crash-<время>.txt` — создаётся при сбое: версия, сообщение и место
  паники, стек вызовов и хвост журнала (в нём могут быть пути файлов, которые не удалось прочитать или
  удалить — посмотрите перед отправкой). При следующем запуске SpaceTree сообщит, где лежит отчёт.

Настройки (⚙) → «Диагностика» открывают эту папку или копируют диагностический текст в буфер обмена —
приложите его к сообщению об ошибке. Снимки сканирований лежат в `%APPDATA%\SpaceTree\snapshots`
(текстовый файл на сканирование, по 40 последних для каждого места); их можно отключить в настройках.

## Сборка

Нужен Rust (stable, edition 2024) и MSVC.

```powershell
cargo build --release            # target\release\SpaceTree.exe и spacetree-cli.exe
cargo test --workspace
powershell -ExecutionPolicy Bypass -File scripts\make_cert.ps1   # один раз: создать сертификат для подписи
powershell -ExecutionPolicy Bypass -File scripts\release.ps1     # тесты, сборка, подпись, артефакты в dist\
```

Структура:

- `crates/core` — модель дерева, сканеры (обход папок, NTFS MFT), статистика, поиск мусора, поиск
  дубликатов, снимки и их сравнение, CSV;
- `crates/app` — GUI на egui, установщик, автообновление, интеграция с Проводником, диагностика, демо-режим;
- `crates/cli` — `spacetree-cli scan C:\ --top 20 --cleanup --dupes --csv out.csv`.

Тот же exe работает как установщик, если называется `SpaceTree-Setup.exe` (или запущен с `--install`),
и как деинсталлятор с `--uninstall`.

Пересоздать скриншоты (выдуманные данные, ничего реального не сканируется и не пишется):

```powershell
SpaceTree.exe --screenshots docs\screenshots
```
